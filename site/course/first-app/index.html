Your first app

A prompt is one JSON document. Its app member is the spec, and the rest is optional. This page writes a prompt for a cinema ticket price, then checks it.

Kai Developer new to Prism

“Show me each command and what it prints.”

A tutorial: follow the steps in order. Each one works if the one before it did.

The parts of a prompt

app memberWhat to writeIn the example
purposeWhat the app decides, in one sentencethe price band of one cinema ticket
fieldsA request is these values in order, separated by spacesage (0 to 120), member (no or yes)
outcomesLower-case words; invalid is reservedfree, reduced, full
ruleswhen and then, in order; the first match decides4 rules
otherwiseThe answer when no rule matchesfull
propertiesnever or always; each becomes a theoremno child or senior pays full; under-3s are free
examplesRequests and their answers; each becomes an acceptance vector5 examples
limitsWhat the app does not decidea member under 3 still goes free

The whole prompt

Save it as ticket.prompt.json. The builder accepted it: 3 properties, 29 acceptance vectors and 82 files.

The whole prompt 38 lines
{
  "schema": "prism/prompt/1",
  "pattern": "decisionTable",
  "goal": "Decide what a cinema ticket costs, so no child or senior is ever charged the full price.",
  "repository": "OWNER/prism-ticket-price",
  "app": {
    "name": "ticket-price",
    "title": "Ticket price",
    "purpose": "Decide the price band of one cinema ticket from the visitor's age and whether they hold a member card.",
    "fields": [
      {"name": "age", "kind": "number", "min": 0, "max": 120, "means": "the visitor's age in whole years"},
      {"name": "member", "kind": "choice", "values": ["no", "yes"], "means": "whether the visitor shows a member card"}
    ],
    "outcomes": ["free", "reduced", "full"],
    "meanings": {"free": "no charge", "reduced": "the reduced price", "full": "the full price"},
    "rules": [
      {"when": [{"field": "age", "op": "<", "value": 3}], "then": "free", "why": "under-3s go free"},
      {"when": [{"field": "age", "op": "<", "value": 16}], "then": "reduced", "why": "children pay the reduced price"},
      {"when": [{"field": "age", "op": ">=", "value": 65}], "then": "reduced", "why": "seniors pay the reduced price"},
      {"when": [{"field": "member", "op": "is", "value": "yes"}], "then": "reduced", "why": "members pay the reduced price"}
    ],
    "otherwise": "full",
    "otherwiseWhy": "an adult without a card pays full price",
    "properties": [
      {"kind": "never", "when": [{"field": "age", "op": "<", "value": 16}], "then": "full", "why": "no child pays full price"},
      {"kind": "never", "when": [{"field": "age", "op": ">=", "value": 65}], "then": "full", "why": "no senior pays full price"},
      {"kind": "always", "when": [{"field": "age", "op": "<", "value": 3}], "then": "free", "why": "babies are always free"}
    ],
    "limits": ["a member under 3 still goes free"],
    "examples": [
      {"request": "2 no", "response": "free"},
      {"request": "10 no", "response": "reduced"},
      {"request": "30 no", "response": "full"},
      {"request": "30 yes", "response": "reduced"},
      {"request": "70 no", "response": "reduced"}
    ]
  }
}

Check it on the command line

git clone https://github.com/afflom/prism-devrel.git && cd prism-devrel
node builder/cli.mjs check ticket.prompt.json
node builder/cli.mjs build ticket.prompt.json --out my-app
Ticket price: Decision table (OMG DMN 1.5, hit policy FIRST), 82 files, 29 acceptance vectors
TP-01: The app never answers full when age is below 16
TP-02: The app never answers full when age is at least 65
TP-03: The app always answers free when age is below 3
...

With the senior rule removed, the real builder refused the prompt and named the request that breaks it:

refused: INV-002 does not hold. The request `65 no` meets "age is at least 65",
and the rules answer full (otherwise). Change a rule, or restate the property.
exit=2

Build it in the browser

Open the builder at /start. Pick an example, edit the prompt and build the app. It runs in the page and sends nothing anywhere.

tutorialMarkdown

Words on this page 4
acceptance test
An input and the output the app must give for it. The holo replays each one before it is offered.
prompt
One JSON document (prism/prompt/1) that describes an app. The builder turns it into every facet of a Prism model.
spec
The app member of a prompt (prism/spec/1): purpose, fields, outcomes, rules, properties, examples and limits.
property
What the app must never or always answer. Each one becomes a theorem the Lean kernel proves for every request.
