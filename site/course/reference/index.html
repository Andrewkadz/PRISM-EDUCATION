Terms

Rule
A when and then line. Rules are tried in order, and the first match decides. Tested, not proved.
Example
A request with its exact expected answer. It becomes an acceptance vector carried in the app.
World
What the program may use. Today that is hologram:guest/core-wasm@1, which allows nothing.
Verdict
The result of a policy check: the level, pass or fail, and every reason (prism/verdict/1).
Hosted verifier
The service at mcp.uor.foundation. It checks and proves models when the SDK image is not on your machine.
just vv
The complete acceptance gate of a template repository, run in the pinned SDK image.

Words marked on any page, such as property and policy, are defined at the foot of that page.

Commands

# Set up the agent path (preview first)
npx prism-code@latest setup --dry-run
npx prism-code@latest setup

# Look, replay, judge, run
npx prism-code inspect app.holo
npx prism-code vectors app.holo
npx prism-code check app.holo --policy policy.json [--json]
npx prism-code run app.holo "<request>" --policy policy.json --rm
npx prism-code run app.holo --port 8080 --policy policy.json

# Catch changed answers between builds
npx prism-code record app.holo --output history.json
npx prism-code replay history.json --image new.holo

# Share
npx prism-code push app.holo dir://./store:1.0
npx prism-code pull dir://./store:1.0 pulled.holo

# Prompt path, from a clone of afflom/prism-devrel
node builder/cli.mjs check prompt.json
node builder/cli.mjs build prompt.json --out my-app
node builder/cli.mjs schema

Words on this page 7
record
One entry in a facet: a component, a threat, a measure or a journey step, with the place in the source it came from.
SDK
Software development kit. Here, the PrismPM container image that builds, checks and verifies Prism models.
acceptance test
An input and the output the app must give for it. The holo replays each one before it is offered.
MCP
Model Context Protocol: an open protocol through which AI agents call tools such as the Prism builder.
property
What the app must never or always answer. Each one becomes a theorem the Lean kernel proves for every request.
evidence level
How much signed evidence an app carries: P0 none, P1 a build record, P2 also a proof, P3 also a replay.
policy
The rule for which evidence level is enough to run an app. The default asks for P2.
