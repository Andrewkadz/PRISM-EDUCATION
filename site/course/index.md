# Prism onboarding course

This course takes you from never having heard of Prism to a verified app of your own. Take the modules in order. Each one ends with a short quiz.

Your progress shows here once you pass a quiz.

## Graded by a proved app

Every quiz answer goes to the Prism course quiz app. It is a Prism app built from this course. Lean proved that it never marks a wrong answer right.

The app runs in your browser. A request is the question number and your option, such as 8 a. It answers correct or incorrect.

## Two ways in

Prism has two front doors. Both share one core: the app member of a prompt is the same prism/spec/1 spec an agent drafts.

|  | Agent path | Prompt path |
| --- | --- | --- |
| You start with | One sentence to your coding agent | One JSON prompt (prism/prompt/1) |
| Tooling | npx prism-code@latest setup (MCP servers and a skill) | The builder at /start, or node builder/cli.mjs |
| --- | --- | --- |
| You get | A proved .holo app file on your machine | A whole repository: every facet, tests and a site |
| Goes live | prism-code push to a registry | GitHub Pages, after just vv passes |
| --- | --- | --- |
| Read | Prism docs: build | Prism-DevRel: start |

## Before you start

- Node.js 22 or later. Modules 3 and 4 run on any laptop.
- No account is needed until module 6. To ship, you need git, the gh CLI and a GitHub account.
- Lean proofs run on the hosted verifier, or on your machine in the SDK image (Docker, about 5.5 GB).
